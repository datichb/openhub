## Critères d'acceptation
1. Session `ticket` en semi-auto : cp-2 apparaît dans **À traiter** avec diff ; validation depuis oh **sans attacher** → l'agent continue ; même validation possible depuis l'interface opencode (première réponse gagne).
2. Question de l'agent → formulaire dans oh ; réponse → l'agent continue.
3. Avant cp-1, l'appel à `developer` est refusé (niveau 3/gating) ; après validation, autorisé.
4. 3 sessions en parallèle suivies dans la vue Sessions ; badge et notifications corrects.
5. Après `migrate deploy-cleanup`, plus aucun fichier de déploiement dans les projets ; les clés utilisateur de `opencode.json` sont conservées.
6. `go build ./...` sans références au moteur de déploiement supprimé.
