### QB8 — État de session évolutif (S8, option 2), derrière une capacité
- **Interface neutre** (`internal/adapters`) : capacité `Capabilities.SessionContext` + méthodes `SetSessionContext(ctx, h, sessionID, key string, value any) error` / `ClearSessionContext(ctx, h, sessionID, key string) error` (noms indicatifs) ; erreur typée `adapters.ErrUnsupported` quand l'outil ne sait pas faire ou que l'API a disparu.
