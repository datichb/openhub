## Objectif
Lancer, en option, un workflow autonome (typiquement `ticket`, `review`, `audit`, `onboarding`) sur un **runner GitLab CI**, avec checkpoints contrôlés par politique, Beads resté sur la machine (instantané/journal) et récupération de la session en local.

## Critères d'acceptation
1. `oh run ticket -t bd-42 --runtime remote` déclenche un pipeline `oh-runner` ; la MR est créée ; aucune `ask` n'est approuvée aveuglément.
2. Au retour : journal rejoué (avec un conflit simulé résolu via la fenêtre), session importée et reprenable en local.
3. Aucun secret de la machine n'est transmis au runner (seules les variables CI).
