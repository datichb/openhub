## Lot 10 — N15 étape B, `Transact` seul chemin d'écriture (`786022d8`)
- Revérifié : ~40 rappels `withWriteLock(fn)` (tous de forme « lire le disque → écrire → `commitAndPush(fichiers)` »), `CommitAndPush` public appelé après des écritures faites **hors verrou** (cmd, TUI, `services/workflow/draft.go`), cinq `"."` (`tracker/sync.go`, `team_solo.go`, `RemovePattern`, `CleanupDoneClaims`, `InitSolo`), synchronisation du suivi = une écriture verrouillée + push **par ticket** puis un `CommitAndPush(".")` final, et `CreateClaimLocal` écrit hors verrou.
- Conception : la transaction voyage dans le **contexte** (`txKey`) ; `activeTx(ctx)` (même clone, chemin canonique). `transact(ctx, keep, build)` : `lockGit` → (verrou d'instance seulement autour des opérations git, **pas pendant la construction** : la construction peut lire par les méthodes publiques sans interblocage) → pull → build → `add -A -- fichiers` → commit → push ; push refusé → `reset --soft` + désindexation + `restore` des fichiers de la transaction puis reconstruction (`keep=false`), ou fichiers gardés tels quels et rebasés par le pull suivant (`keep=true`, `CommitAndPush` public dont les fichiers ont été écrits avant). Transaction imbriquée → jointe.
- `withWriteLock(fn)` = `transact(keep=false)` dont `fn` est la construction ; dans `fn`, `commitAndPush` **déclare** seulement les fichiers et le message (`Tx.Touch`, `addMessage`) ; message final = celui de la construction, sinon de l'unique opération, sinon « premier (+N) ». Dépôt non cloné : `fn` s'exécute (ses erreurs de validation d'abord), `commitAndPush` → `ErrNotCloned` (comportement d'avant gardé). `Pull`, `Push`, `Clone`, `CommitAndPush`, `WithWriteLock`, `Transact` appelés avec le contexte d'une transaction la rejoignent (pas de second verrou ni de second pull).
- **Changements de comportement** : une erreur dans `fn` remet ses fichiers en place (avant : laissés modifiés) ; un push en échec non rejeté (auth) abandonne le commit local au lieu de le laisser en avance (le pull échoue de toute façon d'abord hors ligne) ; le pull « au mieux » après un push réussi a disparu.
- `"."` (ou `./`, `/`, `*`, vide) → `ErrStageAll`. Remplacés : `RemovePattern` (index + `.md`), `CleanupDoneClaims` (chemins des réservations retirées ; liste remise à zéro si la transaction est refaite), `InitSolo` (dépôt neuf, verrou tenu : fichiers non suivis listés par `ls-files --others` puis commit local — pas de transaction, pas de distant), `team_solo` → nouvelle `Repo.CommitWorkflowLayout(ctx, scope, msg)` (les 4 `.gitkeep`), suivi → transaction.
