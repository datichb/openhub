Reprises de `release-v5.0.md` § R, adaptées à la v5.1.

- **R1. Interdits** : aucun `git push`, aucun tag, aucune MR/PR, aucune commande qui publie ; aucune éval, aucun e2e, aucun appel de modèle ; pas de modification de `~/.oh`, `~/.config/opencode` ni de la config git globale. `goreleaser` seulement en `check` et `--snapshot --skip=sign`. **Jamais `oh purge`** (même avec `HOME`/`OH_HOME` temporaires), ni aucune commande destructrice réelle hors des dossiers de test.
- **R2. Un worktree par session** :
  ```bash
  cd /Users/benjamin.datiche/workspace/openhub
  git worktree add ../openhub-wt-v51-<lot> -b feat/v51-<lot> main
  ```
  Un commit par sujet, messages au format du dépôt (`fix: …`, `feat: …`, `docs: …`, `test: …`, `refactor: …` + `(v5.1)`). Pendant le travail, la session ne lance **que les tests de ses paquets**.

- **R4. Modèle des sessions** : `amazon-bedrock/eu.anthropic.claude-sonnet-5-5`.
- **R6. Au plus 3 sessions en parallèle** (une par piste).
- Chaque session lance `make sync-content` avant `go test ./cmd/`.
- **Vérification de l'orchestrateur après chaque fusion**, toujours enchaînée (`&&` ou `set -e`) : `go build ./... && go vet ./... && go test ./internal/archtest/... ./internal/i18n/...` + tests des paquets du lot ; un lot qui touche `cmd/` lance `go test -short ./cmd/` en entier. `go test -short ./...`, **`go test ./cmd/` sans `-short`** (~6 min ; deux régressions cachées par `-short` le 23/10 : `TestTeamInitSolo`, `TestTUIEditorCheck`) et `golangci-lint run ./...` (avec `GOTOOLCHAIN=go1.26.10`) à la fin de chaque vague.
- Avant de pousser : simuler le runner (`HOME` vide, `GIT_CONFIG_GLOBAL=/dev/null`).
- **R5. Fichiers partagés** :
  - locales `cli/internal/i18n/locales/{fr,en}.json` : un préfixe par lot, fusions l'une après l'autre ;
  - `CHANGELOG.md` : écrit **une seule fois** en F1, à partir des récapitulatifs ;
  - `docs/dev/audit-v5.md` : lot 0-B, puis F1 seulement ;
  - fondation de la TUI (`keys/keys.go`, `views/action_list.go`, `views/keys_help.go`, `shell/help.go`) : un seul lot à la fois.
- **Goldens** : jamais régénérés pour faire passer un test ; tout golden modifié est listé et justifié dans le récapitulatif.
- **Lot terminé** quand : tests de ses paquets verts (`-race` pour les paquets concurrents), **et ses propres tests de `cmd/` lancés aussi sans `-short`** (`go test -race -run '<ses tests>' ./cmd/` : leçon du jalon 1, `TestTeamInitSolo` cassé par K1 et caché par `-short`), `go vet` et `golangci-lint` propres sur ses paquets (`GOLANGCI_LINT_CACHE` propre au worktree), récapitulatif écrit (fichiers touchés, entrée CHANGELOG proposée, ruptures, goldens modifiés et pourquoi, risques).
