# inventaire

Inventaire des opérations de logement d'un territoire (bibliothèque Go).

- `operation/` : le modèle, l'import CSV des données des directions départementales, l'export et le DTO du détail.
- `ui/` : le formulaire d'une opération et les deux pages qui l'affichent (détail d'une opération, saisie d'une entrée hors inventaire).
- Tests : `go test ./...`
